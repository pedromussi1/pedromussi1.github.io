Purdle

Live

Four daily word games, generated overnight by an LLM pipeline with no human in the loop. An LLM cannot be trusted to produce a valid puzzle on demand, so generation is a proposal and validation is the authority. Candidates are gated on dictionary membership, word frequency, profanity, recency, and per-game structural checks like embedding novelty and BFS reachability. Failures retry with the validator's feedback fed back into the prompt, and exhausted retries fall back to deterministic selection so the site is never empty.

cite-faithfulness

Research

A RAG system can cite the right page and still say something that page does not support. This reproduces the ALCE citation metric (Gao et al., EMNLP 2023) using natural language inference instead of word overlap, then adds a verifier that flags unsupported citations and re-attributes them to passages that actually entail the claim. The verifier is scored against human-curated gold pages so the judge is never graded by itself, with bootstrap confidence intervals rather than a single number.

paper-tldr

A QLoRA fine-tune of Llama 3.2 3B that rewrites dense scientific abstracts as plain-language summaries. Trained in 41 minutes on a single 12 GB consumer GPU. It beat the zero-shot baseline on every metric reported, across a held-out 618-example test set, at 30% shorter output length. I ran rank and prompt-sensitivity ablations to justify the hyperparameters and documented the overfitting in a model card rather than reporting only the headline.

+13%ROUGE-1
+27%ROUGE-2
+22%ROUGE-L
+4.8%BERTScore F1

ASL-Translator

Live

Real-time American Sign Language fingerspelling to text and speech, running entirely in the browser. No camera frame ever leaves the user's device. The interesting problems were in the pipeline rather than the model: temporal smoothing and motion suppression to stop false letter fires mid-gesture, a word-buffer state machine for repeated letters, and handcrafted trajectory detectors for the motion letters J and Z.

98.06%test accuracy
71.5 KBONNX model
