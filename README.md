# pedromussi1.github.io

Source for my portfolio, live at **[pedromussi1.github.io](https://pedromussi1.github.io)**.

I am an M.S. Artificial Intelligence student at the University of South Florida, graduating December 2027, with a B.S. in Computer Science from the same school. Most of my work sits around LLM systems, retrieval, and on-device computer vision. The part I care about is not getting a model to produce output, it is proving that a change helped.

## Selected projects

| Project | What it is |
| --- | --- |
| [Purdle](https://github.com/pedromussi1/Purdle) | Four daily word games, generated overnight by an LLM pipeline with no human in the loop. Live at [purdle.app](https://purdle.app). |
| [PaperPal](https://github.com/pedromussi1/PaperPal) | Fully local RAG over research papers with page-anchored citations and an evaluation harness. |
| [cite-faithfulness](https://github.com/pedromussi1/cite-faithfulness) | Reproduces the ALCE citation metric using NLI entailment, then checks whether the judge itself can be trusted. |
| [paper-tldr](https://github.com/pedromussi1/paper-tldr) | QLoRA fine-tune of Llama 3.2 3B that beat its zero-shot baseline on every metric reported. |
| [ASL-Translator](https://github.com/pedromussi1/ASL-Translator) | Real-time sign language fingerspelling to speech, running entirely in the browser. [Live demo](https://asl-translator-rosy.vercel.app/). |

Earlier work in computer vision, OCR, and full-stack applications is on my [GitHub profile](https://github.com/pedromussi1).

## Built with

Plain HTML and CSS in a single self-contained `index.html`. No framework, no build step, no dependencies.
